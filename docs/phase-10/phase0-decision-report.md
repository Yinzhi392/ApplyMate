# 阶段 0.15 继续／停止报告

**决策时间：** 2026-08-11T19:02:00+08:00

**样本版本：** `phase0-v1.0`

**决策：** **技术门槛通过，0.17 已获批准**

阶段 0 的十项统一门槛现已全部通过。`jpeg-720-q80` 被锁定为未来 OCR 临时副本规则：保留用户原图，仅向腾讯 OCR 发送 720×1080、质量 80 的 JPEG 临时副本，并在 OCR 后删除两者。产品负责人已于 2026-08-11 明确授权完成 **0.17**，即确认七个低保真线框和本报告的阶段 0 技术继续结论。

该授权范围仅限 0.17 的批准记录；它**不授权** 10.6–10.15、CloudBase 云函数部署、真实运行时 AI 入口、正式发布或任何付费配置。上述后续动作仍须逐项取得产品负责人明确授权。

## 0.11R 修复证据

此前 30 组原始 PNG 评测的中位时延为 19,773.5 ms、最大时延为 55,362 ms，因而触发停止。0.11R 对六个代表性样本的三种图片变体各顺序测试 4 次，三个候选均通过门槛；速度最快的 `jpeg-720-q80` 中位为 1,436 ms。随后对全部 30 组锁定样本顺序复验，得到字段 180/180、准确率 100%、中位 1,429 ms、P95 1,805.2 ms、最大 1,940 ms、超时 0。产品负责人已在调用后确认后付费关闭且实际费用为 0 元。

3,410 ms 仍仅代表“脱敏文本进入 Hy3 后，到本地生成和改写完成”的子管线，不应用它替代 OCR 时延。本结论不提出或授权更换平台、开启付费或降低已锁定门槛。
