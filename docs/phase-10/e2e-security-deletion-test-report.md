## 删除测试边界

本地生产等价领域测试已证明：确认凭证只保存哈希、10 分钟到期、确认后立即禁用、目标用户全部关联数据可清除、其他用户不受影响、匿名指标不可回连、重复 cleanup 无副作用。

为避免不可恢复地删除唯一管理员，云端使用独立随机合成身份完成生产等价演练。管理员只负责创建探针；八个集合各写入一条同时带固定 recordType、精确 probeId 和 `syntheticTest=true` 的记录。cleanup 仅在三项同时匹配时删除。首次执行各集合删除 1 条、残留均为 0；连续重放各集合删除 0。匿名指标稳定为 1 条且不含 userId 或 deletionProbeId。唯一管理员及真实记录不在任何删除条件中。
