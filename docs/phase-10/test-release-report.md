# ApplyMate 测试体验版发布报告

**报告日期：** 2026-08-14

**候选范围：** 微信小程序开发者/体验成员测试

**当前状态：** 真实 AI 体验版代码已部署；`api` 与 `worker` 健康检查为 live，一次真实简历/JD 内容冒烟待体验端完成

**不适用范围：** 正式公开发布、微信正式审核、体验成员以外的用户流量

## 1. 发布建议

当前候选仅适合在已知身份的开发者或体验成员范围内使用。该范围内开启真实简历/JD、腾讯 OCR 和 TokenHub AI 闭环；不提交正式审核、不公开发布，普通账号删除入口仍保持关闭。

## 2. 已完成证据

- 协议、隐私政策和 AI 服务说明已获产品负责人用于邀请制体验版的确认；公开发布前仍需专业复核。
- C01–C30 已人工确认并锁定为 `phase0-v1.0`。
- OCR 全量复验字段 180/180，中位耗时 1,429 ms，最大 1,940 ms，零超时。
- Hy3 事实选择为 178/180（98.89%）；本地确定性生成/改写 60/60 合规，零虚构，端到端中位 3.41 秒。
- 合成外发审计证明图片只到腾讯 OCR，TokenHub 只接收脱敏文本，证据不保存原文或凭证。
- 云端可靠性探针：正常任务终态 `succeeded`；超时任务终态 `failed/TASK_TIMEOUT`。
- 合成删除演练：八个集合各删除 1 条、残留 0；重放删除 0；匿名指标不含 userId 或探针 ID。
- 2026-08-13 最终 `npm run check` 通过格式、样本隔离、敏感扫描、类型、112 个测试文件、408 项测试和五模块构建。
- 2026-08-14 修复了 `api` 同步等待 OCR/模型导致的真机超时：任务改由 SCF Event 异步派发，体验版真实 AI 改写和安全错误提示一并补齐；两个云函数已重新部署且凭证存在性诊断全部通过。
- 修复后的完整 `npm run check` 通过格式、样本隔离、敏感扫描、严格类型、114 个测试文件、413 项测试和五模块构建。

## 3. 零费用复核

产品负责人于 2026-08-13 确认：CloudBase 实际费用 0 元、OCR 后付费关闭、TokenHub 按 Token 计费关闭、腾讯云账单 0 元。任一免费额度耗尽时必须失败关闭，不得自动转付费。

- 产品负责人要求跳过本轮 iOS/Android 真机测试；因此不能声称双端真机通过。
- 因没有第二个微信号，邀请码真实消费、重复消费及第二身份拒绝未完成云端验证。
- 普通真实账号删除入口保持关闭；已通过的是严格隔离的合成删除探针。
- 真实 AI 业务仅限开发者/体验成员；上线前需再完成一次真实简历与 JD 闭环冒烟验证。
- 微信个人主体类目和正式发布资格未完成复核；不升级主体、不转 H5。
- 两个微信开发者工具本地配置不属于阶段提交内容。
- `api` 与 `worker` 已于 2026-08-14 重新部署；当前剩余验证是体验端真实简历与 JD 内容冒烟，以及上传微信开发版本后设为体验版。

## 5. 测试体验版运行边界

- `api` 与 `worker` 必须返回 `acceptsUserTraffic=true` 和 `state=experience_real_ai_live`。
- 仅允许开发者/体验成员通过 CloudBase 上传临时文件；原图只发往 OCR，TokenHub 只接收脱敏文本。
- 不对外公开体验二维码，不邀请超出已知体验成员范围的用户。
- 不开启任何后付费、按 Token 计费或自动续费兜底。
- 出现费用非零、身份越权、敏感信息外发或云函数异常时立即停止测试。
