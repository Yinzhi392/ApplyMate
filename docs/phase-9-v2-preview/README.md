# 阶段 9 全量视觉稿

这是不参与小程序生产构建的静态交互预览，覆盖阶段 9 的 13 个页面。内容全部为合成数据，不连接微信、CloudBase、腾讯 OCR 或 TokenHub。

## 本地查看

在仓库根目录运行：

```bash
python3 -m http.server 4173 --directory docs/phase-9-v2-preview
```

然后打开 `http://localhost:4173/`。左侧可逐页切换；手机画板内可体验登录状态、岗位输入模式、截图增删、岗位提交后直接生成、结果折叠、记录筛选和主要页面跳转。

## 评审边界

- 本稿用于确认信息结构、视觉层级、间距与交互，不读写真实数据。
- 登录页演示邀请码为 `APPLYMATE`。
- 本稿明确通过前，不修改 `miniprogram/pages/` 下的原生 WXML/WXSS。
- 确认后以本稿为基准重写原生页面，再进入微信开发者工具和真机对照验收。
