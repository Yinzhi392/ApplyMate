# ApplyMate Web v2.0 响应式线框

**状态：** 生产实现基线
**适用宽度：** 320 / 360 / 390 / 430px
**视觉方向：** 清爽效率型 + 克制玻璃

## 设计系统

- 颜色：暖白 `#F4F6F1`、墨蓝灰 `#17343B`、青绿 `#26766C`、薄荷雾 `#DDECE6`、暖棕 `#B97845`、白色 `#FFFFFF`。
- 字体：标题使用系统中文黑体 700，正文使用系统中文黑体 400–500，状态数字使用系统等宽字体。
- 结构：最大内容宽度 480px；移动端 16px 外边距；模块间 24–32px；最小触控高度 44px。
- 标志元素：“事实线”以一条细青绿色竖线串联简历、岗位、正文三个阶段；只表达流程，不展示内部证据。
- 禁止：固定页面高度、嵌套卡片、连续渐变、横向滚动、缓存用户内容。

## 响应式验收

- 320px 下三按钮可换为两行但不得越界；390px 起保持单行。
- 键盘弹起时主按钮随文档流移动，不使用覆盖输入框的固定底栏。
- iOS 安全区使用 `env(safe-area-inset-*)`；底部导航预留 Home Indicator。
- 桌面端只把 480px 应用画布居中，不扩展成管理后台式宽屏。
